# 亞丁大陸地形圖

網站：[亞丁大陸地形圖](https://mp678922.github.io/LineageMap/)。GitHub Pages 由 `main` 分支的 `docs/` 發布；共享地標另由 Google 試算表與 Apps Script 提供資料服務。

本機預覽：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory docs
```

開啟 <http://127.0.0.1:8765/>。GitHub Pages 已設定以 `main` 分支的 `/docs` 作為發布來源。

`docs/meta.json` 記錄尺寸與縮放層；`docs/tiles/` 是 gzip 壓縮的數值菱形格資料。瀏覽器最多同時下載 4 塊可見區附近的資料，依視野中心或縮放手勢中心由近到遠安排下載；已下載資料的畫布也每幀優先建立焦點附近的圖塊。已載入的數值資料保留在 32 MB 快取內，畫好的圖塊保留在 96 MB 快取內；移動或縮放時優先重用，超過預算才淘汰不在畫面上的舊圖塊。放大後若舊圖塊的像素密度明顯不足，停住後才逐塊重畫。平移時重用暫存畫布，逐格描邊已停用。較粗的已載入圖塊先當底圖；細圖塊每載入一塊便以 180 毫秒淡入上層，不必等待整層完成。地圖固定採自動細化：先顯示粗格，停住約 400 毫秒後逐級載入更細的格子；龍之谷可由 4 倍格細化至 2 倍格、再到原始細格。拖曳或縮放會取消未完成的細化。

重新產生資料塊：先從來源產生 `terrain-grid.json` 與 `terrain-lod.json`，再執行 `python build_terrain_db.py` 和 `python build_pages_tiles.py`。這些來源與中間檔保留在本機，發布只需 `docs/`。

## 共享地標

地標與地形分開保存。地圖頁面從 Google 試算表讀取地標，其他人開啟同一公開網址即可看到資料。編輯者輸入共用的 4 位數編輯碼後，可在地圖上新增、修改、移動或刪除地標。地標位置記錄在原始菱形格座標，縮放不會改變位置。不需要會員帳號，編輯碼由 Apps Script 在伺服器端讀取私人試算表的 `Settings!B2` 驗證。驗證成功後，瀏覽器會把編輯碼保存在有效期 30 天的 Cookie；下次開啟網頁會先向服務驗證，通過後才顯示編輯功能。按「結束編輯」會刪除 Cookie。

按「新增座標」會進入專用選點模式：一般控制與既有座標暫時隱藏，滑鼠移動時預覽吸附的菱形格位置。點一下地圖才會開啟座標編輯表單；拖曳仍用來移動地圖，滾輪仍可縮放。按「取消」或 Esc 可退出選點模式；觸控裝置直接點選位置。移動既有座標仍沿用原本操作。

選定位置後仍維持專注模式，只顯示編輯表單及目前位置的圖釘與菱形格。表單列出目前格子編號；拖曳圖釘可吸附到其他原始菱形格，格子編號隨之更新。拖曳地圖空白處仍可平移；儲存成功或取消後才恢復一般介面。

座標面板分為「座標清單」與「編輯模式」兩個頁籤。清單頁籤維持一般訪客視角；切到編輯頁籤後，未驗證者只會看到密碼入口。驗證通過才顯示新增、編輯和拖曳功能，登出按鈕位於編輯頁籤底部。切回清單頁籤或關閉面板會暫時離開編輯視角並重新鎖定座標，但保留已驗證的編輯身分及 Cookie；回到編輯頁籤即可繼續，不需再次輸入密碼。

選取既有座標時，編輯表單的位置旁會出現鎖頭。解鎖後可直接拖曳該座標；拖曳期間，半透明標記會留在起點。放開後會儲存新的菱形格位置；連續拖曳會按順序排隊寫入，寫入期間仍可繼續拖曳。若最後一次寫入失敗，標記會回到最後成功儲存的位置並顯示錯誤。一次只會解鎖目前選取的座標；切換座標、關閉面板或登出會重新鎖定。一般清單頁籤及未驗證訪客看不到鎖頭。

啟用步驟：

1. 已建立私人地標資料表；不要公開分享它的編輯權限，也不要在此公開倉庫記錄管理連結。
2. 已將 `apps-script/Code.gs` 貼到綁定的 Apps Script 專案並儲存；專案編輯連結應保存在私人位置。
3. 私人資料表的 `Settings!B2` 已有 4 位數編輯碼。可直接在該格查看或更換；不要將資料表公開分享，也不要把編輯碼填進 GitHub 或 `docs/`。
4. 已將 Apps Script 部署為「以我的身分執行」與「所有人」可存取的[網頁應用程式](https://script.google.com/macros/s/AKfycbxoiFDHyNq49YB444Kes8T5vIdMqdPbi-hoA7KMCG0PNigx3wvMIwMXBUty_4i3Fh0/exec)。服務僅要求操作這份試算表的權限。修改 Apps Script 程式後需更新既有部署作業的版本。
5. 服務網址已填入 `docs/landmark-config.js`，GitHub Pages 網站已發布。網址不含編輯碼。

訪客只讀取公開地標資料，`Settings` 工作表及編輯碼不會由公開讀取接口傳出；寫入與刪除都需在 Apps Script 驗證編輯碼。瀏覽器每 30 秒、以及回到分頁時更新一次地標。Apps Script 的跨網域讀取使用只含公開資料的 JSONP；寫入採 POST，並用一次性操作識別碼查詢結果。若顯示「無法確認操作結果」，先重新讀取地標，避免重複新增。知道編輯碼的人都能編輯全部地標。
